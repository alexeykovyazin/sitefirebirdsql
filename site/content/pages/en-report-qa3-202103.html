January to March 2021

March 2021
  • Created / modified QA tests for ~60 tracker tickets
  • Found / reported bugs: CORE-6500, CORE-6503, CORE-6504, CORE-6517, CORE-6527, CORE-6528
  • Reported FB crashing when run test functional.util.gbak_zip on Linux
  • Misc changes in qa-rundaily.sh
  • Changes in fbt-cross-report.py related to work both on Linux and Windows
  • Discussed with Vlad Khorsun ability to add into trace log info about statements restart
  • Reported FB hanging during execution test for CORE-6163
  • Linux, run tests on FB 4.0.0.2377: got crashes for CORE-6437
  • Discussed with Pavel Cisar features of parsing .fbt file structure
  • WI-V3.0.8.33420: can not create mapping with name longer than 16 non-ascii characters
  • Test for CORE-6469, Linux only: need to increase delay before closing trace session, otherwise trace log remain incomplete
  • First scratch of web page with overall QA results for different OS and major FB versions
  • Discussed with Pavel Cisar features of trace API usage in FDB
February 2021
  • Created / modified QA tests for ~30 tracker tickets
  • QA-scenarios: continued implementation for launch fbt_run Linux
  • Suggestions and features request for fbtest: sent final list to Pavel Cisar
  • Multiple small changes / fixes  in qa-rundaily scenario for Linux
  • Discussed with Alex Peshkov implementation details of test for CORE-6023
  • Reported to Dmitry Yemanov that backported bugfix for CORE-6486 and CORE-6487 was incomplete
  • Ran tests on Linux, build 4.0.0.2372, CS: 4 core dumps detected
  • QA-rundaily scenario, on Linux: gfix crashes three times during run test for CORE-6437
January 2021
  • Created / modified QA tests for ~30 tracker tickets
  • Found / reported bugs: CORE-6463, CORE-6464, CORE-6469, CORE-6470, CORE-6476
  • QA scenarios: start deep refactoring of Windows batch files
  • Discussed with Vlad Khorsun implementation details of test for CORE-5832
  • Reported FB 4.0.0.2335 crashing when performing test "functional\tabloid\max-path-length.fbt"
  • Discussed with Alex Peshkov ability to see in trace activity for database that is self-security
  • Reported multiple failed fbt-tests (and several crashes) on build 4.0.0.2349
  • QA scenarios: start implementation of rundaily.sh for run all fbt tests on Linux
  • QA: collected fbtest improvement suggestions
  • Tested special build 4.0.0.2317 with patch for CORE-6458
  • Reported crash of build LI-V3.0.7.33388, SS
