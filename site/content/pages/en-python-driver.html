Official Python Drivers

There are two official Python drivers:
  1. The firebird-driver package provides driver for Python 3.8+ and Firebird 3+. This driver uses new Firebird OO API provided by fbclient library. You can download it or install directly from Python Package Index.
  2. The FDB package provides legacy driver for Python  2 and 3, and Firebird 2.x and 3. This driver uses classic Firebird API provided by fbclient library. You can download it or install directly from Python Package Index.
