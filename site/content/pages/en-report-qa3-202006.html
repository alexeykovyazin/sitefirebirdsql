February to May 2020

May 2020
  • Created / modified QA tests for 6 tracker tickets
  • Migrated 4 tests from GTCS
  • Found / reported bugs: CORE-6297
  • OLTP-EMUL, 4.x Classic and SuperClassic: command to change DB state to full shutdown can hang
  • Found problem in FDB driver: delay for 5 seconds can occur after closing connection
  • FB 4.x (builds 1969 and 1970) crashed several times while running tests for CORE-4571 and CORE-5034
  • Implemented test for new metadata storage mechanism (requested by Alex Peshkov)
  • CORE-6309 still has a problems when we want to retrieve info about ~255 limbo transactions
  • OLTP-EMUL: compared memory consumption on standard and special build (with new metadata storage)
  • Refactored several QA batch files
  • OLTP-EMUL improvements
April 2020
  • Created / modified QA tests for >30 tracker tickets
  • Migrated 18 tests from GTCS
  • Found / reported bugs: CORE-6290, CORE-6291
  • Reported regressions for CORE-1313, CORE-2031, CORE-2068, CORE-5034
  • Refactored test that checks 'CREATE OR ALTER USER ... TAGS (...)'
  • Reported bug in the new sorting method (experimental build)
  • Discussed issues re. "ALTER DOMAIN ADD <new_constraint> DROP CONSTRAINT" -- different behaviour between v3 and v2.5
  • Reported bugchecks due to ODS changes (new RDB$ tables added)
  • OLTP-EMUL, 3.0.6.33289 CS: command to shutdown DB does not return to OS
  • OLTP-EMUL, 4.x CS / SC: unexpected violations of CHECK constraint
  • fbt-cross-report: changes in code that generates HTML report
March 2020
  • Created / modified QA tests for 18 tracker tickets
  • Started migration of GTCS test to FBT (~60 tests completed)
  • Found / reported bugs: CORE-6264
  • Updated FDB driver on the QA servers after a bugfix
  • Reported crashes for CORE-6015
  • Reported WI-V3.0.6.33259 SC freezing in production
  • Reported bugcheck "record disappeared (186)" for WI-V3.0.6.33259
February 2020
  • Created / modified QA tests for 23 tracker tickets
  • Found / reported bugs: CORE-6241, CORE-6247, CORE-6248, CORE-6251
  • OLTP-EMUL: changes for generating and uploading HTML report when running on Linux
  • OLTP-EMUL: generated etalone databases for regular runs
  • Reported crash discovered with WI-3.0.5.33212, SS
  • fbt-cross-report: further steps in order to reduce size of generated html
  • Reported regressions for CORE-1760, CORE-4310, CORE-5545
  • Reported crash discovered with LI-V3.0.5.33187 SS
  • fbt-cross-report: refactoring

Pavel Zotov
Moscow, Russian Federation
