June to September 2018
 

September 2018
 
Built-in replication:
  • Avoid races during configuration read
  • Preserve original char-case for filenames
  • Fixed races during nbackup
  • Minor refactoring of the replica-side code
  • Extensions for change sets in the new API
Other:
  • v3.0.4 release: docs and publishing
August 2018
 
Built-in replication:
  • Replicate DDL with the correct owner
  • Finished master-side merge
July 2018
 
Built-in replication:
  • Set restricted file permissions while segment is being copied
  • Resolve symlinks before matching the database name against the config
  • Slightly reworked syncronous mode processing
June 2018
 
Built-in replication:
  • Refactor replication internals (change block format)
  • Optimized metadata redundancy
Bugfixing:
  • Fixed not synchronized access to the shared list of attachments
