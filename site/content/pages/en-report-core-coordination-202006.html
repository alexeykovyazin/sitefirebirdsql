March to June 2020
 
June 2020
 
New development:
  • Refactored the code backing DBKEY concatenation for views
Bugfixing:
  • CORE-4985: Non-privileged user can implicitly count records in a restricted table (re-fixed)
  • CORE-6335: INSERT ... RETURNING does not require a SELECT privilege
  • Backported CORE-5982 into the v2.5 codebase
Other:
  • v3.0.6: documentation and release management
May 2020
 
New development:
  • Make the reschedule accounting simpler and sweep more responsive under load
Other:
  • v4 Beta 2: documentation and release management
April 2020
 
New Developement
  • DDL control for replication
  • Allow the replication state to be changed at runtime
  • Support for replication segments larger then 4GB
  • Minor replication improvemens
  • Refactored the global objects to be managed from a single place
  • CORE-6278: Efficient table scans for DBKEY-based range conditions
March 2020

New Developement
  • Finished implementation of lateral derived tables
Bugfixing:
  • CORE-6266: Deleting records from MON$ATTACHMENTS using ORDER BY clause doesn't close the corresponding attachments
  • Front ported solution for CORE-6216
  • One more fix for possible hangs inside the monotoring shmem code
  • Fixed some bugs in the alternative sorting method being developed

Dmitry Yemanov
