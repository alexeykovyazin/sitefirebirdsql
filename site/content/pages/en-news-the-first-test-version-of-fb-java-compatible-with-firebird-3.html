The first test version of FB/Java, compatible with Firebird 3.0.0

FB/Java is an External Engine plugin for Firebird that makes Firebird capable of run functions, procedures, and triggers made in the Java platform.

Download it now:https://github.com/FirebirdSQL/fbjava/releases

It complements Jaybird making it interface with Firebird engine and handling the infrastructure necessary to support user routines. It also has a client utility with functions to install and uninstall the plugin in a database and those users may use to deploy and un-deploy Java classes and resources stored in JAR files to a database.

Bugs should be filed in the GitHub project. This test version uses a modified snapshot of Jaybird 3.0.
