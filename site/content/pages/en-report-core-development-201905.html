October 2018 to January 2019

October 2018

master

  • Fix of unnecessary wait for prepared but still active concurrent transaction, see CORE-5930.

B3_0_Release

  • Fixed bug CORE-5935 : Bugcheck 165 (cannot find tip page)
  • Fixed bug CORE-5936 : Firebird server segfaults in the end of database backup
  • Fixed bug CORE-5949 : Bugcheck could happen when read-only database with non-zero linger is set to read-write mode.

B2_5_Release

  • Fixed bug CORE-5935 : Bugcheck 165 (cannot find tip page)
  • Fixed bug CORE-5936 : Firebird server segfaults in the end of database backup

November 2018

master

  • Enable "Enhance Optimized Debugging" to produce more useful debug info (.pdb files)
  • Fixed bug bug CORE-5959 : Firebird returns wrong time after changes of time zone
  • Update WIndows build

B3_0_Release

  • Backport fix for bug CORE-5959 : Firebird returns wrong time after changes of time zone

B2_5_Release

  • Fixed bug CORE-5958 : FB 2.5.8 hangs

December 2018

master

  • Rename setting: TpcBlockSize -> TipCacheBlockSize
  • Correct usage of different time units in IdleTimer.

January 2019

master

  • Update Windows ICU version to 63.1
  • Make old compilers (not supporting C++11 "noexcept") work with new ICU
  • Ported fix for bug CORE-5980 : Firebird 2.5.6 & 25.8 server crash
  • Fixed bug CORE-5991 : Trace could not work correctly with quoted file names in trace configurations
  • Fixed bug CORE-5993 : When creation of audit log file fails, there is no error message in firebird.log
  • Fixed bug CORE-5995 : Creator user name is empty in user trace sessions

B3_0_Release

  • Ported fix for bug CORE-5980 : Firebird 2.5.6 & 25.8 server crash
  • Fixed bug CORE-5991 : Trace could not work correctly with quoted file names in trace configurations
  • Fixed bug CORE-5993 : When creation of audit log file fails, there is no error message in firebird.log
  • Fixed bug CORE-5995 : Creator user name is empty in user trace sessions

B2_5_Release

  • Fixed bug CORE-5980 : Firebird 2.5.6 & 25.8 server crash
