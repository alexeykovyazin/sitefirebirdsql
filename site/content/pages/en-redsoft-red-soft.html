РЕД СОФТ

Сотрудники РЕД СОФТ плотно сотрудничают с сообществом Firebird и сами являются его активными разработчиками.

СУБД Ред База Данных https://reddatabase.ru/

Разрабатывается компанией РЕД СОФТ с 2006 года. СУБД Ред База Данных основана на исходных кодах Firebird, но имеет ряд доработок. Многие из них включены в последующие версии Firebird. Часть разрабатывалась совместно с командой разработки Firebird Foundation. Например:

  • nbackup - 2007
  • трейс - 2009
  • контроль доступа к DDL операциям - 2014
  • кумулятивные роли и группы - 2016
  • поддержка части SQL SECURITY - 2016
  • синхронная и асинхронная репликация - 2019
  • целостность запросов и промежуточная сборка мусора - 2019

Техническая поддержка

Профессиональная техническая поддержка на всех этапах эксплуатации баз данных. Доступны несколько тарифных планов: от поддержки по электронной почте до выделенного менеджера в режиме 24/7.

Консультации

РЕД СОФТ предлагает консультационные услуги по проектированию баз данных, подбору и настройке оборудования и ОС, по обслуживанию и оптимизации баз данных Firebird.

Аудит сервера СУБД

Обследование сервера СУБД и формирование рекомендаций по дальнейшей эксплуатации.

Восстановление баз данных

РЕД СОФТ оказывает услуги по восстановлению поврежденных баз данных. Услуга может быть оказана посредством удаленного подключения к серверу заказчика или с передачей архива поврежденной базы данных на сервер РЕД СОФТ.

Обучение

РЕД СОФТ проводит online курс “Администрирование СУБД Firebird/RedDatabase”. Подробнее с программой курса можно ознакомится https://reddatabase.ru/services/

RED SOFT

RED SOFT engineers collaborate with the Firebird community on implementing new features.

 

RedDatabase https://reddatabase.ru/

RedDatabase has been developed by RED SOFT since 2006. It is based on the Firebird sources and has extra features and enhancements, which the company returns back in the following Firebird versions. Some features have been developing in collaboration with the developers of the Firebird Foundation. For example:

  • nbackup - 2007
  • trace - 2009
  • DDL access control - 2014
  • cumulative roles - 2016
  • SQL SECURITY - 2016
  • sync and async replication - 2019
  • snapshot consistency and intermediate garbage collection - 2019

Technical support

The company provides professional technical support for any tasks. There are various plans from Email consulting to a dedicated engineer available around the clock.

Consulting

There are a set of services for database design, hardware selection and OS tuning, maintaining and optimizing Firebird databases.

Database server audit

RED SOFT offers the audit of your database servers with recommendations for the following optimization.

Database repair

The company has the skill to rescue your data after database corruption. The service can be provided via remote connection or uploading a corrupted database to our cloud.

Online training

RED SOFT can make online training on the course “Administration of Firebird/RedDatabase”. Find the detailed program on the page https://reddatabase.ru/services/
