February to May 2019
 
May 2019
 
New development:
  • Embedded replication state storage (work in progress)
Bugfixing:
  • Fixed DDL replication for non-UTF8 charsets
  • Fixed missing build step for udrcpp_example on Windows
  • Refactoring after the CORE-5074 bugfix
April 2019
 
New development:
  • Replication monitoring support (work in progress)
  • Embedded replication state storage (work in progress)
Bugfixing:
  • Fixed inconsistent alignment beetween 32-bit and 64-bit replication sides
March 2019
 
New development:
  • Core implementation of lateral derived tables
Bugfixing:
  • Fixed inconsistency in reserved vs non-reserved words (time zone support)
February 2019
 
Bugfixing:
  • Ensure that the newly archived replication segment is immediately flushed to disk
  • Ignore replication configuration changes made in runtime (until server restart)
  • Allow nbackup to be run on the replica side

Dmitry Yemanov
Penza, Russia
