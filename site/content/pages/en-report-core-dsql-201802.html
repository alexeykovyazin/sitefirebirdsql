October 2017 to January 2018

January 2018

trunk
  • Fixed UDR compatibility functions for databases with UTF8 as default charset.
  • Continued work on time zone support.
  • Fixed CORE-5719 - FB >= 3 crashes when restoring backup made by FB 2.5.
  • Fixed CORE-5717 - Reject non-constant date/time/timestamp literals (branch work/time-zone-support).
3.0 branch
  • Fixed CORE-5706 - Trace config with misplaced "{" lead firebird to crash.
  • Fixed CORE-5713 - Field alias disapears in complex query.

December 2017

trunk
  • Continued work on time zone support.

November 2017

trunk
  • Finished feature CORE-5620 - Builtin functions FIRST_DAY and LAST_DAY.
  • Improvement CORE-5647 - Increase number of formats/versions of views from 255 to 32K.
  • Started work on time zone support.
  • Finished fix for CORE-5611 - Higher memory consumption for prepared statements in FB3.
  • Finished fix for CORE-5646 - Parse error when compiling a statement causes memory leak until attachment is disconnected.

October 2017

trunk
  • Working in CORE-5611 - Higher memory consumption for prepared statements in FB3.
  • Verifying pull request #111 - Do not scan function if compiling not needed.
  • Fixed CORE-5638 - Wrong result with index on case-insensitive collation using NUMERIC-SORT.
  • Started feature CORE-5620 - Add builtin functions LAST_DAY and FIRST_DAY.
  • Working in CORE-5646 - Parse error when compiling a statement causes memory leak until attachment is disconnected.
3.0 branch
  • Backported fix for CORE-5638 - Wrong result with index on case-insensitive collation using NUMERIC-SORT.
  • Fixed CORE-5645 - Wrong transaction can be passed to external engine.
other
  • Analyzed fbtcs migration to git.
Adriano dos Santos Fernandes
