September to December 2020

December 2020
  • Created / modified QA tests for 15 tracker tickets
  • Found / reported bugs: CORE-6460
  • OLTP-EMUL: reworked CONNECT/DISCONNECT triggers because of new system variable RESETTING
  • OLTP-EMUL: developed reports for estimating efficiency of ExtConnPool usage
  • Reported test for CORE-2668 hanging on build 3.0.8.33400 (Classic)
  • OLTP-EMUL: re-implemented exceptions handling block
  • Refactored several tests after noticing false failures on build 4.0.0.2298 (related to the results ordering)
November 2020
  • Created / modified QA tests for ~50 tracker tickets
  • Found / reported bugs: CORE-6441, CORE-6445, CORE-6447, CORE-6450, CORE-6453
  • OLTP-EMUL: updated table fb_errors with actual gdscodes and messages text
  • Reported build 4.0.0.2260 crash while executing "ALTER EXTERNAL CONNECTIONS POOL CLEAR ALL"
  • fbt_cross_report: changed SIMILAR-TO pattern for detect message about possible FB crash
  • OLTP-EMUL, regular launches on POSIX host: multiple crashes since build 4.0.0.2271
  • OLTP-EMUL: deep rework related to test External Connections Pool feature
  • OLTP-EMUL: reported two crashes on build 3.0.8.33392 (SS, Linux)
  • Investigated how different context variables from the SYSTEM namespace affects the performance
  • OLTP-EMUL: reported several crashes on build 4.0.0.2272
October 2020
  • Created / modified QA tests for ~20 tracker tickets
  • Found / reported bugs: CORE-6414, CORE-6415
  • OLTP-EMUL: checked build 33357 (compiled with gcc 4.8.3)
  • OLTP-EMUL: reported crashing build 4.0.0.2214 SS when changing DB state to full shutdown + several runs testing the fix
  • Refactored auxiliary script that runs .fbt-tests
  • CORE-5302: reported performance regression since Jan-2020
  • Refactored script that checks FB crashes on Windows (watch4dumps.bat)
  • Read consistency / statement-level restarts: started to implement tests which use PSQL
  • Reported crash on FB 3.x and 4.x when PSQL code contains infinite loop of SP calls
  • Reported unexpected SQLSTATE while running test for CORE-5685
  • Implemented test checking presence of all necessary files inside the snapshot build
  • Reported failed tests for CORE-3639 and CORE-6285
  • OLTP-EMUL: reported crash on build 4.0.0.2228, related to setLockAttachment
September 2020
  • Created / modified QA tests for 7 tracker tickets
  • Found / reported bugs: CORE-6411
  • Refactored tests functional/transactions/read-consist-sttm-restart*
  • fbt-cross-report: implemented new report that shows distribution of known (standard) FB errors per tests/builds
  • Fixed script that makes FB snapshot builds
  • Reported fbt-run hanging on 4.0.0.2194 Classic during test for CORE-4298
  • Reported several crashes for OLTP-EMUL when DB is in backup-lock state
  • Reported crashing build 4.0.0.2195 when ran .sql with mon$ queries
  • Tested VARCHAR vs BLOB network transmission performance, with/without WireCompression
  • Finished creation of SQL-related tests for check statement-level restart
  • OLTP-EMUL: several changes / improvements

Pavel Zotov
Moscow, Russian Federation
