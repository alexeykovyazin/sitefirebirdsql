March to June 2019
Activities for period
  • Implemented Firebird 4 time zone support (JDBC-540)
  • Backported JDBC-541 (default character set support for database creation) to Jaybird 3.0.6
  • Other issues worked on: JDBC-519, JDBC-555, JDBC-564, JDBC-576, JDBC-583, JDBC-584
  • Worked on Jaybird manual
  • Created pull request to add Firebird support to Flyway (https://github.com/flyway/flyway/pull/2376)
  • Created pull request to add Firebird support to testcontainers-java
  • PR was denied, created separate library (firebird-testcontainers-java)
  • Working on improving support in Hibernate
  • Working on new asynchronous Firebird driver for Java using the R2DBC API
  • Released Jaybird 2.2.15 (last 2.2.x version), Jaybird 3.0.6, Jaybird 4.0.0-beta-1
Planned/expected activities June - July
  • Working on improving Firebird support in Hibernate
  • Working on improving Firebird support in IntelliJ IDEA and related tools
  • Working on new asynchronous Firebird driver for Java using the R2DBC API
  • Small miscellaneous tasks for Jaybird 4
  • Working on Jaybird manual

Mark Rotteveel
Delft, The Netherlands
