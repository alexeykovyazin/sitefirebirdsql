June - September 2018

June-July 2018

  • Found / reported bugs: CORE-5839, CORE-5846, CORE-5848, CORE-5848, CORE-5850, CORE-5858
  • Created / modified QA tests for 21 tracker tickets
  • Deep refactoring of batch script for watching dumps FB on Windows, validation of PDB, creating stack traces
  • Detected very poor performance of SIMILAR TO in some border cases
  • Investigated stack traces (POSIX): get number of threads that really do some work in a current moment
  • Tested 3.0.4 by OLTP-EMUL with intensive usage of monitoring tables
  • Various replication tests
August 2018
  • Created / modified QA tests for 26 tracker tickets
  • OLTP-EMUL: benchmark of built-in vs trigger-based replications
  • Regression in 4.0 was found by analyzing results of test for CORE-5167
  • Adjusted tests for 4.0 due to introduction of new TIL = read consistency
  • OLTP-EMUL: check for memory leaks - no leaks detected
  • Discuss with Pavel Cisar current wishlist for fdb / fbtest
September 2018
  • Found / reported bugs: CORE-5907, CORE-5926, CORE-5931
  • Created / modified QA tests for 9 tracker tickets
  • Database shutdown can take too much time on SuperClassic because of new attachments coming
  • OLTP-EMUL: 12h test on special build (validation of memory pool statistics)
  • Insert bulk of records into GTT and force deletion of attachment lead to unnecessary UNDO
  • OLTP-EMUL: continued refactoring
  • Reading / discussing the TPC-C standard (v5, 2001): what can be ported into OLTP-EMUL
 
Pavel Zotov

Moscow, Russian Federation
