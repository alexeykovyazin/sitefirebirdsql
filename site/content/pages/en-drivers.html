Jaybird is a JDBC driver suite to connect to Firebird database servers.

This driver is based on the well-known JDBC standard.

Jaybird 6 requires Java 17 or higher, while Jaybird 5 requires Java 8 or higher.

The Jaybird JDBC driver is distributed free of charge under the GNU Lesser General Public License (LGPL). Text of the license can be obtained from http://www.gnu.org/copyleft/lesser.html.

For more information please refer to the Jaybird JDBC Driver Java Programmer’s Manual.

For the latest released version, see Downloads > JDBC Driver

Full version history of Jaybird is available on the GitHub Jaybird releases page.
