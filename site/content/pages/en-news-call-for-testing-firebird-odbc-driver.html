Call for testing Firebird ODBC driver

The new version of Firebird ODBC driver is in Beta stage now. The new version uses new Object Oriented Firebird client API, works only with Firebird 3+, and requires fbclient.dll from Firebird 3 or above.

Version 3.0 Beta is available for testing on Windows: https://github.com/FirebirdSQL/firebird-odbc-driver/wiki

Please download, test, and report any issues!

Issues can be reported here: https://github.com/FirebirdSQL/firebird-odbc-driver/issues
