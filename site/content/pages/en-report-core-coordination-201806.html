February to May 2018
 

May 2018
 
Built-in replication:
  • Remove redundant charset convertion
  • Refactor replication internals (changeset format)
Bugfixing:
  • Fixed inconsistency in request/transaction state after error
  • Attempt to fix corruption of the monitoring shared data
  • Fixed crash during database shutdown
April 2018
 
Built-in replication:
  • Allow GTT modifications in replica
  • Fixed replicated DFW errors
  • Fixed database variable header parsing
  • Refactored replication internals (master-side sync/async processing)
Bugfixing:
  • Enhanced Vlad's solution for early monitoring initialization
March 2018
 
Built-in replication:
  • Fixed journal rewind after master->replica copying
  • Refactor replication internals (journal)
February 2018
 
Built-in replication:
  • Log replication conflicts as warnings
  • Fixed the attachment mutex regression
  • Refactor replication internals (CDC API)
Bugfixing:
  • Avoid reading the page buffer after it was released
  • Fixed ISQL after changes in gds__vax_integer()
  • Fixed the hash join regression introduced recently
  • CORE-5756: FB crashes when trying to recreate table that is in use by DML
 
Dmitry Yemanov

Penza, Russia
