Many updates of Firebird drivers: Firebird.NET, Jaybird Embedded, Ruby Extension. PHP 6.1.1. RC2, RUST

ADO.NET Data provider FirebirdClient 10.3.4.0 is released with a few fixes:  FirebirdClient 10.3.4.0

Mark Rotteveel released a new version of jaybird-embedded-win32-x86-64:5.0.3.0-alpha-1, providing the Firebird 5.0.3 win32-x86-64 binaries (that is: 64-bit Windows):  Firebird Embedded Windows x86-64 for Jaybird

Ruby Extension library update 

PHP Firebird driver 6.1.1-RC.2 is released . Please test thoroughly and report any issues.

Firebirust v0.5.4 is released with a few changes: This release adds inspectable column metadata to statements, tightens and cleans up several internal APIs, expands tests.

PyFirebirdSql 1.4.1 is released with a few bug fixes and internal changes.

A modern C++ wrapper for the Firebird database API.
