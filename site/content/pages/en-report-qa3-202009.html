June to August 2020

August 2020
  • Created / modified QA tests for >70 tracker tickets
  • Found / reported bugs: CORE-6379, CORE-6387, CORE-6396
  • Reported regression for CORE-4091 and CORE-5246
  • Reported several DECFLOAT-related tests failing since build 4.0.0.2097
  • Reported many tests failing since build 4.0.0.2173
  • Benchmarked the custom build FB 3.x (3.0.7.33357) with improved monitoring
  • Reported two tests failing after fixing CORE-6395
  • OLTP-EMUL: ran 100 sessions + trace with config with all options turned ON. Purpose: check that no more "Unknown tag (0) in isc_svc_query()" fail occurs
July 2020
  • Created / modified QA tests for >50 tracker tickets
  • Found / reported bugs: CORE-6353, CORE-6355, CORE-6356, CORE-6357, CORE-6365, CORE-6366, CORE-6369, CORE-6374
  • Implemented a number of INT128 tests
  • INT128 tests: re-checked again issues from COREs: 6353, 6355, 6356, 6357, 6291
  • Reported several test failures starting from build 4.0.0.2100
  • Started implementing tests related to statement-level restart which can occur in RC read consistency mode
  • Refactored script that makes daily builds
  • Reported new optimizer regressions in build 4.0.0.2119
June 2020
  • Created / modified QA tests for 30tracker tickets
  • Implemented test that verifies sufficiency of minimal set of DML privileges for appropriate actions
  • Implemented test for comparing RDB$DB_KEY values which are returned from VIEWS based on several tables (with using JOINs and UNIONs)
  • Additional test for FULL JOIN and WHERE which references to one of involved tables
  • Found / reported bugs: CORE-6336, CORE-6340
  • Found error 'no permission for read/select access to TABLE' in v2.5 (fix wasn't backported from higher versions)
  • Reported test failures for build 4.0.0.2027
  • Reported unstable results for test functional/GTCS/gtcs_cast_datatypes.fbt
  • Reported several examples with wrong results for INT128 datatype, mostly with MOD() and BIN* functions
  • OLTP-EMUL: overall report with results gathered from different FB versions
  • OLTP-EMUL: first scratch of HTML cross-report with overall results

Pavel Zotov
Moscow, Russian Federation
