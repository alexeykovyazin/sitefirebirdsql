October to December 2020
 
December 2020
 
New development:
  • CORE-2650: Improve ORDER BY performance when long VARCHARs are involved
  • Make returned data types in replication API consistent with MessageMatadata
  • Restore the ability to recreate the replica using nbackup
  • Better compatibility with future replication protocol extensions
  • A bit denser data encoding inside the replication stream
Bugfixing:
  • Fixed wrong defaults for client auth plugins
November 2020
 
Bugfixing:
  • CORE-6440: expression indices with COALESCE cannot be matched
  • Ensure the sub-query cursor is closed after error
October 2020
 
New Developement
  • Avoid replicating transaction-level savepoint
  • Add dedicated primary error code for replication failures
  • Make error handling in replication plugin API consistent with the rest of the API
  • Replace ADD/DROP with INCLUDE/EXCLUDE in replication DDL
Bugfixing:
  • Make unique file IDs optional (switchable via firebird.conf)
Other:
  • v3.0.7 release
