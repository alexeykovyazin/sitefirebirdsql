November 26, 2025

Many updates of Firebird drivers: Firebird.NET, Jaybird Embedded, Ruby Extension. PHP 6.1.1. RC2, RUST

Several Firebird-related tools and libraries have been updated across multiple programming languages, including ADO.NET Data provider FirebirdClient, Jaybird embedded binaries for Windows, PHP Firebird driver, Ruby Extension library, Firebirust with enhanced column metadata and improved APIs, PyFirebirdSql with bug fixes, and a new modern C++ wrapper for the Firebird database API, demonstrating continued active development across the Firebird ecosystem.
