June to September 2019

August-September
  • Created / modified QA tests for 20 tracker tickets
  • Found / reported bugs: CORE-6134, CORE-6139, CORE-6141
  • Reported that query involving huge table (> 500 million rows) can work too long before reacting on the statement cancellation via MON$STATEMENTS
  • Several changes in the script that daily runs QA tests
  • SIMILAR TO problems were detected on several tests after FB4 started using 're2' library
  • Reported that ALTER VIEW executed in a loop leads to huge memory consumption
July
  • Created / modified QA tests for 27 tracker tickets
  • Found / reported bugs: CORE-6103
  • Deep refactoring of batches making snapshot builds and QA runs
  • Investigated problem with non-linear growth of restore for large database (650 GB)
June
  • Created / modified QA tests for 13 tracker tickets
  • Found / reported bugs: CORE-6080
  • OLTP-EMUL: attempt to refactore client-order procedure, reduce lock-contention in XQD* tables
  • Minor OLTP-EMUL adjustments
  • Reported (with stack dumps) a number of server crashes
Pavel Zotov
Moscow, Russian Federation
