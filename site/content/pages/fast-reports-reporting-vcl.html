FastReport Reporting VCL (Vendor: Fast Reports)

FastReport Reporting VCL is a comprehensive band-oriented report generator designed for creating professional reports and documents. Whether you need invoices, financial reports, product catalogs with color profile support, restaurant menus, sales details, questionnaires with electronic forms, airline tickets, or utility bills, FastReport provides the perfect solution for making your data visually understandable.

Key Features

Modern Report Designer

The modern editor offers many tools for creating report templates with flexible architecture that allows you to create editors for existing and new objects. The template designer can be integrated directly into your application and supports localization for more than 30 languages.

Band-Oriented Architecture

Features a rich set of bands for creating various types of reports. You can collect common elements such as titles, headers, business details, and logos into a basic report template and inherit them for other reports. The system also supports nested reports functionality.

Database Connectivity

Supports data sorting and filtering with master-detail relationships that can be set up with just a few mouse clicks. Connects to FireDAC, ADO, BDE, DBX, IBX, and FIBPlus to access most databases, including Firebird. Reports can contain data from tables, queries, and database connections.

Scripting Engine

Includes a powerful scripting engine that supports PascalScript, C++ Script, BasicScript, and JScript. Reports can include dialog forms for requesting parameters before building, with dialog controls that allow you to connect data and filter it without writing code.

Export Capabilities

Extensive export filters allow you to save finished reports to numerous formats including:

  • PDF (versions 1.4-1.7, PDF/A-1a, PDF/A-1b, PDF/A-2a, PDF/A-2b, PDF/A-3a, PDF/A-3b)
  • Microsoft Office formats: XLSX, RTF, DOCX, PowerPoint
  • Web formats: HTML, MHT, XML, XAML
  • Text formats: TXT, CSV
  • Image formats: JPEG, BMP, PNG
  • Open Document formats: ODT, ODS, ODP
  • Other formats: XPS, SVG, ZPL, Excel OLE

PDF Integration

Quickly convert reports with editable fields (text fields, combo boxes, checkboxes, radio buttons, and graphics fields) into PDF documents without connecting additional libraries. Supports secure, accessible, and reliable PDF formats.

Platform Support

Part of the Ultimate solution that enables creation of business projects on VCL, Lazarus, and FMX platforms. The package includes FastScript for fast processing of scripts of any complexity and the visual SQL query builder FastQueryBuilder. Also provides access to client-server reporting tools on VCL and Lazarus.

Interactive Features

The Report Viewer's preview window allows detailed examination of prepared reports. Supports working with parameters, multi-level detailing, and interactive reports. You can define responses to mouse clicks on objects in the preview window, such as building and displaying detailed reports about clicked objects.

Flexible Printing Options

Offers various printing capabilities including:

  • Cutting large report pages into smaller ones
  • Printing several small pages on one large page
  • Printing in preset formats with scaling
  • Support for printing A3 pages on regular A4 printers

Pricing Tiers

FastReport Reporting VCL is available in multiple editions with pricing starting from $499 to $1,299, offering different feature sets including FastReport Engine, VCL components, FMX components, Lazarus components, OLAP features, data connections, reporting features, report objects, barcodes, charts, printing capabilities, export formats, source code access, converters, and transport options.
