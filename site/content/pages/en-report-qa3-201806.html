February - May 2018

May 2018

  • Found / reported bugs: CORE-5822, CORE-5826, CORE-5827
  • Created / modified QA tests for 13 tracker tickets
  • Found and reported that metadtata extracting ( isql -x ) contains GRANT expression with incomplete syntax
  • Implemented auxiliary script that watches for ability to restore metadata and gather info about possible errors
  • Found and reported that QA test for CORE-4464 shows poor performance for 4.0 Classic 4.0.0.955
  • Found and reported crash on LI-V3.0.4.32952 during database shutdown
  • Implemented batch script for watching dumps FB on Windows, check PDB, creating stack traces
April 2018
  • Found / reported bugs: CORE-5803
  • Created / modified QA tests for 10 tracker tickets
  • Found and reported that GTT is not allowed to be modified on replica databases (but it should)
  • Tested replication after promoting the master database to the slave
  • Found and reported crash on LI-V2.5.9.27103, when attachments are deleted via "delete from mon$attachments"
March 2018
  • Created / modified QA tests for 19 tracker tickets 
  • Implemented auxiliary script for permanent checking of difference between master and slave sequences value
  • Found inconsistency while replicating generators
  • LI-V2.5.9.27103, SC - could not drop attach via 'delete from mon$attachments', sent backtrace to developers
  • Found and reported QA test failure (CORE-3490 failed since 21.03.2018, build 32936)
February 2018
  • Found / reported bugs: CORE-5751, CORE-5756
  • Created / modified QA tests for 13 tracker tickets
  • Reported dumps and stack traces when 'service firebird stop' actually did not stopped FB daemon
  • Resumed refactoring of Python script which makes direct scan of database file (without database connection)
  • Found regression in ISQL (FB 3.x) since build 32854

Pavel Zotov

Moscow, Russian Federation
